# РАБОЧАЯ ПРОГРАММА ДИСЦИПЛИНЫ «Компьютерные технологии» (3 семестр)

28 аудиторных часа. Экзамен
## Программа курса

**1. Введение в параллельные вычисления (2 часа)**
* Архитектуры параллельных систем: многоядерные процессоры, кластеры, системы с общей и распределённой памятью.
* Основные проблемы: параллелизм, конкуренция, синхронизация, «бутылочные горлышки».
* Цели и задачи курса.

**2. Технология OpenMP (8 часов)**
* Модель параллелизма (fork/join).
* Основные директивы: `parallel`, `for`, `section`.
* Область видимости переменных (shared, private).
* Синхронизация: критические секции, замки (`lock`), атомарные операции, барьеры (`barrier`).
* Практические задания: параллелизация циклов (формула трапеции, сортировка).
* Анализ проблем: ложное разделение кэша, планирование циклов.

**3. Технология MPI (8 часов)**
* Модель передачи сообщений.
* Базовые функции: `MPI_Init`, `MPI_Comm_size`, `MPI_Comm_rank`.
* Взаимодействие: точка-точка (`MPI_Send`, `MPI_Recv`), коллективные операции (`MPI_Bcast`, `MPI_Reduce`).
* Производные типы данных.
* Практические задания: параллельная сортировка («чёт-нечёт»), умножение матрицы на вектор, формула трапеции в MPI.
* Анализ быстродействия: оценка накладных расходов на коммуникацию.

**4. Элементы модели MapReduce (6 часов)**
* Парадигма: функции Map и Reduce, этап Shuffle.
* Типичные задачи: WordCount, умножение матриц, операции реляционной алгебры.
* Практическое задание: реализовать упрощённую версию MapReduce (например, подсчёт слов) с использованием MPI для передачи данных между «узлами».

**5. Гибридные подходы и оптимизация (4 часа)**
* Когда имеет смысл комбинировать OpenMP и MPI (например, OpenMP внутри процессов MPI для загрузки отдельных узлов кластера).
* Стратегии оптимизации: балансировка нагрузки, минимизация коммуникаций, векторизация.
* Инструменты анализа: профилировщики (например, Intel VTune, OmpProf), инструменты для MPI (MVAPICH, OpenMPI tools).
* Разбор реальных кейсов: где какая технология уместна, а где приводит к потерям.
