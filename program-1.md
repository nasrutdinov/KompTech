4. Научиться проводить полноценный вычислительный эксперимент: от обработки данных до интерпретации результатов.
5. Интегрировать навыки: оформить результаты ML-эксперимента в виде полноценной научной статьи.

## 3. Содержание тем

### Блок 1. LaTeX и научная публикация (20 часов)

**Тема 1. Базовая верстка и математический аппарат (2+2)**
Структура документа, классы (`article`, `report`), пакеты `amsmath`, `amssymb`, `amsthm`. 
Многострочные уравнения, матрицы, выравнивание. Пакет `cleveref` для умных ссылок.

**Тема 2. Библиография и векторная графика (2+2)**
`BibLaTeX` + `biber`, стили цитирования (ГОСТ, APA, IEEE). 
Введение в TikZ: координаты, узлы, стили. Пакет `tikz-cd` для коммутативных диаграмм, 
`pgfplots` для графиков функций.

**Тема 3. Презентации Beamer и научные шаблоны (2+2)**
Темы, фреймы, блоки, перекрытия (`\pause`, `\only`). 
Шаблоны научных журналов (Springer LNCS, IEEE, Elsevier). 
Работа с `\maketitle`, аннотациями, ключевыми словами.

**Тема 4. Продвинутые пакеты и автоматизация (2+2)**
Кастомные команды (`\newcommand`, `\newtheorem`), окружения. 
Пакеты `booktabs` (научные таблицы), `listings` и `minted` (вставка кода). 
*Makefile / `latexmk` для автоматической компиляции.*

**Тема 5. Совместная работа и Overleaf (2+2)**
Работа в Overleaf: совместное редактирование, версионирование. 
Экспорт в Word (через pandoc). Конвертация между форматами. 
\Управление большими проектами (`\include`, `\input`).

### Блок 2. Подготовка к курсу «Машинное обучение» (32 часа)

**Тема 6. Git, среда Python, Jupyter (2+2)**
Git: ветки, слияния, разрешение конфликтов, `.gitignore`. Conda/venv. 
Jupyter Notebook/Lab,  magic-команды (`%timeit`, `%debug`).

**Тема 7. NumPy: векторные вычисления и линейная алгебра (2+2)**
ndarray, `np.einsum`, `np.linalg` (разложения, собственные значения). 
Векторизация vs циклы. 

**Тема 8. Pandas: работа с данными (2+2)**
Series, DataFrame. Загрузка (csv, sql, excel), фильтрация, `groupby`, `pivot_table`, `merge`, `concat`. Работа с пропусками, временными рядами (`datetime`).

**Тема 9. Matplotlib и Seaborn: научная визуализация (2+2)**
Figure, Axes, subplot. Гистограммы, scatter, heatmap, boxplot. 
Настройка стилей для публикаций (размер шрифтов, DPI, векторные форматы PDF/SVG).

**Тема 10. Scikit-learn: задачи классификации (2+2)**
 Логистическая регрессия, KNN, Decision Tree, Random Forest. Метрики: accuracy, precision, recall, F1, ROC-AUC. Матрица ошибок.

**Тема 11. Scikit-learn: задачи регрессии и Pipeline (2+2)**
Линейная регрессия, Ridge, Lasso, ElasticNet. Метрики MSE, MAE, R². `Pipeline` и 
`ColumnTransformer` для воспроизводимости пайплайнов.

**Тема 12. Предобработка и Feature Engineering (2+2)**
Масштабирование (`StandardScaler`, `MinMaxScaler`, `RobustScaler`). 
\Кодирование категориальных признаков (`OneHotEncoder`, `OrdinalEncoder`, `TargetEncoder`). Генерация полиномиальных признаков.

**Тема 13. Кросс-валидация и подбор гиперпараметров (2+2)**
`cross_val_score`, `KFold`, `StratifiedKFold`. `GridSearchCV`, `RandomizedSearchCV`. 
Анализ кривых обучения (learning curves) для диагностики переобучения.

### Блок 3. Интеграция (4 часа)

**Тема 14. Итоговый проект: защита и рецензирование (2+2)**
Подготовка финального отчета в LaTeX. Взаимное рецензирование (peer-review) 
между студентами. Публичная защита проекта (5-7 минут + вопросы).

## 4. Задания для практических занятий

### Пара 1. Базовая верстка и математика
Сверстать 2-3 страницы научного текста с теоремами, леммами, доказательствами. Набрать многострочное уравнение с выравниванием, вставить матрицу (Якобиан или Гессиан). Использовать `cleveref` для ссылок.

### Пара 2. Библиография и TikZ
Нарисовать коммутативную диаграмму (точная последовательность или граф марковского процесса) через `tikz-cd`. Создать BibTeX-файл с 5+ источниками и оформить список литературы по ГОСТ.

### Пара 3. Beamer и научные шаблоны
Создать презентацию Beamer на 7-10 слайдов по теме из области математики. Использовать темы, блоки, вставку TikZ-графики. Применить шаблон LNCS или IEEE для короткой заметки.

### Пара 4. Продвинутые пакеты и автоматизация
Создать кастомные команды для часто используемых обозначений (например, `\R`, `\N`, `\E` для мат. ожидания). Оформить таблицу с `booktabs` (без вертикальных линий). Написать Makefile для автоматической компиляции.

### Пара 5. Совместная работа и Overleaf
Работа в парах: каждый студент редактирует свою секцию статьи в Overleaf, затем происходит слияние. Разрешить смоделированный конфликт версий. Экспортировать результат в PDF и (опционально) в DOCX через pandoc.

### Пара 6. Git и Jupyter
Создать репозиторий, настроить `.gitignore`, виртуальное окружение. Создать Jupyter-ноутбук с проверкой версий библиотек. Сделать коммит, создать ветку, слить через Pull Request.

### Пара 7. NumPy
Реализовать вычисление матрицы попарных евклидовых расстояний между двумя наборами векторов ($N \times D$ и $M \times D$) **без циклов** через Broadcasting и `np.einsum`. Сравнить время с наивной реализацией. Решить систему линейных уравнений и найти собственные значения матрицы.

### Пара 8. Pandas
Загрузить датасет (например, Titanic). Заполнить пропуски (медиана/мода). Сгруппировать данные по двум признакам (`groupby`), построить сводную таблицу (`pivot_table`). Объединить два DataFrame через `merge`.

### Пара 9. Визуализация
Построить heatmap матрицы корреляций, scatter-plot с раскраской по классу, распределение целевой переменной. Настроить стили для публикации (шрифты, DPI, подписи осей). Сохранить графики в PDF и SVG.

### Пара 10. Классификация
Обучить 3 классификатора (Logistic Regression, KNN, Random Forest) на датасете. Построить матрицу ошибок, ROC-кривые для каждого метода. Сравнить метрики accuracy, precision, recall, F1, ROC-AUC.

### Пара 11. Регрессия и Pipeline
Решить задачу регрессии (например, California Housing). Сравнить LinearRegression, Ridge, Lasso. Построить `Pipeline`, включающий масштабирование и модель. Проанализировать коэффициенты Lasso для отбора признаков.

### Пара 12. Предобработка и Feature Engineering
Создать `ColumnTransformer` для раздельной обработки числовых и категориальных признаков. Применить `StandardScaler` и `OneHotEncoder`. Сгенерировать полиномиальные признаки через `PolynomialFeatures`.

### Пара 13. Кросс-валидация
Провести 5-fold кросс-валидацию для выбранной модели. Использовать `GridSearchCV` для подбора гиперпараметров (например, `C` и `kernel` для SVM). Построить learning curves для диагностики переобучения.

### Пара 14. Защита проекта
Подготовить LaTeX-отчет (4-10 страниц) и презентацию. Провести взаимное рецензирование. Публично защитить работу (5-7 минут).

## 5. Итоговые проекты (2 типа × 5 вариантов)

### Требования ко всем проектам (повышенные, с учетом увеличенного объема):
1. **Код:** Jupyter-ноутбук на GitHub с воспроизводимыми результатами, векторизованными вычислениями, docstrings.
2. **Отчет:** Научная статья в LaTeX (шаблон LNCS/IEEE), 6-12 страниц.
3. **Обязательные разделы:** Аннотация, Введение, Математическая постановка, Описание данных, Методы, Результаты (с графиками и таблицами), Анализ ошибок, Заключение, Список литературы (8+ источников).
4.  Обязательное сравнение **не менее 3 моделей**, анализ переобучения через learning curves, интерпретация результатов.

---

### Тип проекта А: «Прикладной анализ данных и предсказательное моделирование»

1. **Прогнозирование стоимости недвижимости (California Housing).** Задача регрессии. Анализ мультиколлинеарности, сравнение Linear/Ridge/Lasso/ ElasticNet. Интерпретация коэффициентов.
2. **Предсказание оттока клиентов (Telco Churn).** Классификация на несбалансированных данных. ROC-AUC, PR-AUC, F1. Анализ важности признаков через `feature_importances_` и SHAP (опционально).
3. **Классификация вин с PCA (Wine).** Понижение размерности, анализ собственных чисел ковариационной матрицы, критерий Кайзера. Влияние PCA на качество классификации.
4. **Прогноз спроса на велосипеды (Bike Sharing).** Работа с временными метками, циклические признаки (sin/cos). Сравнение деревьев решений, случайного леса и градиентного бустинга.
5. **Диагностика заболеваний (Breast Cancer Wisconsin).** Калибровка вероятностей (Platt scaling), калибровочные кривые. Минимизация ложноотрицательных срабатываний.

### Тип проекта Б: «Сравнительный анализ алгоритмов на синтетических данных»

1. **Классификация на многообразиях (Moons, Swiss Roll, Circles).** Линейные vs нелинейные ядра SVM. Kernel PCA. Визуализация границ решений.
2. **Проклятие размерности для метрик расстояния.** Данные из многомерных нормальных распределений (10–1000D). Сравнение евклидовой, манхэттенской, косинусной, махаланобисской метрик в KNN.
3. **Аппроксимация функций: полиномы, сплайны, ядерная регрессия.** Феномен Рунге, Bias-Variance decomposition. Сравнение качества аппроксимации.
4. **Кластеризация смесей гауссовских распределений.** K-Means vs DBSCAN vs GMM. Математический вывод E- и M-шагов EM-алгоритма в тексте статьи.
5. **Устойчивость регрессии к выбросам и гетероскедастичности.** OLS vs Huber vs RANSAC vs квантильная регрессия. Данные с ошибками из распределения Коши/Стьюдента. Анализ доверительных интервалов.

## 6. Формы контроля

**Текущий контроль (40%):** Качество выполнения заданий на 14 парах. Оценивается корректность кода, LaTeX-верстки, активность на занятиях.

**Итоговый контроль (40%):** Защита итогового проекта:
- Качество кода и воспроизводимость (10%)
- Качество LaTeX-отчета (10%)
- Математическая глубина анализа (10%)
- Качество презентации и ответы на вопросы (10%)
